# Brain Tumor Classification Using Deep Learning

## Overview

This project implements and compares multiple Deep Learning models for Brain Tumor Classification using MRI images.

The objective is to identify whether an MRI scan contains a brain tumor by leveraging Convolutional Neural Networks (CNNs) and Transfer Learning techniques.

## Models Implemented

* Custom CNN
* VGG16 Transfer Learning
* ResNet50 Transfer Learning
* ResNet50 Fine-Tuning

## Features

* Image preprocessing and augmentation
* Automated training and validation pipeline
* Transfer learning using pretrained models
* Performance comparison across architectures
* Confusion matrix and classification report generation
* Prediction on custom MRI images
